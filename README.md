# ML-Based Packet Loss Prediction
Machine learning-based prediction of packet loss in computer networks.
## Project
This project combines Computer Networks and Machine Learning to predict packet loss based on network performance metrics.

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the full architecture, dataset design, and development plan. Environment validation and setup notes are in [docs/ENVIRONMENT_SETUP.md](docs/ENVIRONMENT_SETUP.md); the Phase 1 network experiment foundation is documented in [docs/PHASE_1_NETWORK_EXPERIMENT.md](docs/PHASE_1_NETWORK_EXPERIMENT.md). Live network experiments require WSL2 + Mininet, which are still being validated on the development machine.
